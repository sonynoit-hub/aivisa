# 卡片设计优化说明

## 优化总结

将页面内容展示全面升级：
1. **JSON 卡片**：从单一容器升级为独立的现代化卡片组件
2. **Markdown 内容**：统一视觉风格，与 JSON 卡片保持一致

---

## 视觉升级对比

### JSON 卡片

#### 之前 (Old Design)
- ❌ 所有卡片在一个大白色容器内
- ❌ 用简单 `<hr>` 分隔
- ❌ Emoji 只有 20px，不够醒目
- ❌ 列表项用默认 prose 样式，不够突出
- ❌ 按钮样式简单
- ❌ 缺少悬浮效果和微交互

#### 现在 (New Design)
- ✅ **独立卡片**：每个卡片是独立的 `<article>`，带阴影和边框
- ✅ **悬浮效果**：hover 时卡片阴影加深，边框变色
- ✅ **大图支持**：支持 `imageUrl` 字段，可展示封面图（48-56px 高度）
- ✅ **大号图标**：Emoji 升级到 32-40px，或自定义图标在 40-48px 圆形容器内
- ✅ **自定义列表**：
  - bullets 用绿色勾选图标 (✓)，无标题
  - detail 用灰色圆点，浅灰背景容器，无标题
- ✅ **增强按钮**：
  - 主按钮：渐变色 + 阴影 + 上浮动效
  - 次按钮：2px 边框 + 悬浮效果
- ✅ **响应式优化**：移动端和桌面端图标、标题、间距自适应

### Markdown 内容

#### 之前 (Old Design)
- ❌ 大圆角 (rounded-3xl) 与卡片不统一
- ❌ 默认 prose 样式，与品牌色不符
- ❌ 缺少悬浮效果
- ❌ 链接颜色为默认蓝色

#### 现在 (New Design)
- ✅ **统一卡片样式**：与 JSON 卡片相同的 rounded-2xl + 边框 + 阴影
- ✅ **悬浮效果**：hover 时阴影加深，边框变色
- ✅ **品牌色应用**：
  - 链接使用品牌色 `#04c4b6`
  - 列表标记使用品牌色
  - 引用块左边框使用品牌色
- ✅ **优化排版**：
  - 标题层次分明（h2 带下划线）
  - 代码块深色背景 + 圆角 + 阴影
  - 表格带边框和斑马纹
  - 图片圆角 + 阴影
- ✅ **统一间距**：与 JSON 卡片的 padding 和 margin 保持一致

## 支持的字段列表

### 标题与描述
- `title` / `name` / `heading` / `label` - 主标题
- `subtitle` / `subTitle` / `sub_title` - 副标题
- `desc` / `description` / `lead` / `text` / `content` - 描述文本

### 视觉元素
- `emoji` - Emoji 表情（推荐使用，显示为大图标）
- `icon` - 自定义图标字符（当没有 emoji 时使用）
- `imageUrl` / `image_url` / `image` - 封面图片 URL
- `pill` / `badge` / `tag` - 标签文字

### 列表内容
- `bullets` - 特徴列表（数组，带绿色勾选图标）
- `detail` - 詳細列表（数组，带信息图标和灰色背景）

### 行动按钮
- `url` / `href` / `ctaUrl` / `cta_primary_url` / `ctaPrimaryUrl` - 主按钮链接
- `cta_primary` / `ctaPrimary` / `ctaLabel` - 主按钮文字（默认：詳しく見る/查看详情/Learn more）
- `cta_secondary` / `ctaSecondary` - 次按钮文字
- `cta_secondary_url` / `ctaSecondaryUrl` - 次按钮链接

### 其他
- `variant` - 预留字段，支持不同视觉风格（目前未使用）

## Markdown vs JSON 对比

### JSON 卡片的优势（已优化）
✅ **视觉控制精确**：每个元素都有专属样式  
✅ **交互效果丰富**：悬浮、点击、动画都能精细控制  
✅ **结构清晰**：数据结构化，易于维护和国际化  
✅ **组件化**：可以轻松添加新的视觉元素（如图片、评分、进度条）  
✅ **响应式友好**：不同元素在移动端和桌面端可以有不同表现  

**推荐用于：**
- 服务介绍卡片
- 价格方案
- 功能特性列表
- 流程步骤
- 招聘信息
- 案例展示

### Markdown 的优势（已优化）
✅ **自由排版**：作者可以自由组织内容  
✅ **富文本支持**：支持标题、列表、引用、代码块、表格等  
✅ **SEO 友好**：文章型内容更适合搜索引擎  
✅ **编辑简单**：非技术人员也能轻松编辑  
✅ **品牌色统一**：现已应用品牌色到链接、列表、引用块  
✅ **卡片风格统一**：与 JSON 卡片相同的外观和悬浮效果  

**推荐用于：**
- 长文章/博客
- 法律条款
- 详细说明文档
- FAQ 详解
- 复杂排版内容（表格、代码块）

## 设计原则

1. **视觉层次**
   - 大标题 (text-xl/2xl) → 副标题 (text-sm/base) → 正文 (text-sm/base)
   - 用颜色区分重要性：slate-900 > slate-700 > slate-600 > slate-500

2. **间距系统**
   - 卡片间距：`space-y-6` (24px)
   - 卡片内边距：`p-6 sm:p-8` (24px → 32px)
   - 元素间距：`mb-5` (20px) 为标准，标题下 `mb-2/3`

3. **交互反馈**
   - 悬浮效果：阴影加深 + 边框变色
   - 按钮悬浮：`-translate-y-0.5` 轻微上浮
   - 图片悬浮：`scale-105` 轻微放大
   - 过渡时间：`duration-200` 快速响应，`duration-300/500` 用于卡片和图片

4. **可访问性**
   - 所有图标都有相邻文字说明
   - 按钮有明确的视觉焦点状态
   - 颜色对比度符合 WCAG AA 标准
   - 外部链接自动添加 `target="_blank"` 和 `rel="noopener noreferrer"`

## 总结

**JSON 卡片现在可以做到：**
- ✅ 更现代、更美观的视觉设计
- ✅ 丰富的交互效果（悬浮、动画）
- ✅ 灵活的内容结构（图片、图标、列表、按钮）
- ✅ 更好的可读性和信息层次
- ✅ 支持单个卡片对象和卡片数组两种格式

**Markdown 现在可以做到：**
- ✅ 与 JSON 卡片统一的外观（圆角、阴影、边框）
- ✅ 品牌色应用（链接、列表、引用块）
- ✅ 悬浮效果与 JSON 卡片一致
- ✅ 优化的排版（标题层次、代码块、表格）
- ✅ 保持 Markdown 的灵活性和易编辑性

**建议使用策略：**
1. **JSON 卡片**用于**结构化、简短**的内容（服务、特性、方案）
2. **Markdown** 用于**长文本、复杂排版**的内容（文章、说明）
3. 两者可以在同一页面共存，视觉风格统一，互补使用

**页面渲染顺序：**
```
JSON 卡片（cards）
    ↓
Markdown 内容（descriptionMd）
```

现在两种格式都很美观，视觉风格完全统一！🎨
